# 织梦者の乌托邦服务器公开投稿物品归档

本服务器以 **CraftEngine** 为基础，采用世界共建的社区发展模式，鼓励具有创作能力与相关资源的玩家参与服务器内容的设计、制作与建设。

本仓库用于公开归档玩家向服务器投稿的物品、方块、道具及其相关材质、模型等资源。

## 投稿须知

由于服务器整体架构的特殊性，不同类型的内容对于服务器的影响存在较大差异。

删除自定义生物通常不会对服务器整体运行造成严重影响；但删除已经投入使用的方块、物品或其他基础资源，可能导致已有世界数据、玩家物品、配方及其他游戏内容出现兼容性问题。

因此，当您主动向本服务器投稿**方块、物品、道具及其相关材质、模型等资源**时，即视为您同意按照以下方式授权：

1. 您确认自己拥有所投稿内容的相应权利，或已经获得足以进行本次投稿的授权。
2. 所投稿的方块、物品、道具及其相关材质、模型等内容，采用 **CC BY-ND 4.0（署名-禁止演绎 4.0 国际）**协议进行分发。
3. 本服务器及其运营者可以在服务器及相关项目中使用、复制、传播和展示上述投稿内容，包括将其用于商业或非商业用途。
4. 为使投稿内容能够正常运行，服务器运营者可以对文件进行**必要的技术性处理**，例如文件格式转换、压缩、重命名、目录调整、资源包整合以及适配服务器运行环境等。此类处理仅用于技术适配，不构成对作品本身的公开衍生发布。
5. 除法律另有规定或作者另行授权外，本仓库及服务器不会将投稿内容制作成允许他人自由修改并再次发布的衍生作品。
6. 投稿内容在服务器中的长期存在可能产生对世界数据、玩家物品、配方及其他内容的依赖。因此，投稿后作者原则上不应要求服务器立即删除已经投入使用的内容。具体处理方式以服务器运营规则及双方另行约定为准。

### 自定义生物

与方块、物品及道具不同，自定义生物及其相关角色设计、模型、设定等内容，原则上由原作者保留相应权利。

作者向服务器投稿自定义生物，并不意味着将其著作权或其他相关权利转让给服务器运营者。

服务器仅在获得投稿授权的范围内使用相关内容。
